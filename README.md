
# Учебный план: Full-Stack CRM Разработка (9 месяцев)

> **Цель курса:** Подготовка junior-разработчиков «с нуля» до уровня, позволяющего самостоятельно проектировать и внедрять модули в архитектуру образовательной CRM-системы.
> **Регламент:** 36 недель / 1 раз в неделю / 2 часа (120 минут).

---

## Календарный план по модулям

### Блок 1: База и контроль версий
***Сентябрь** | Обучение командной разработке и проектированию сеток интерфейса.*

- [ ] **Неделя 1**: Архитектура клиент-сервер. Git и GitHub. Команды `git init`, `add`, `commit`, `push`, основы ветвления (`git branch`).
- [ ] **Неделя 2**: Продвинутый CSS. Flexbox и CSS Grid. Проектирование каркаса главного дашборда CRM.
- [ ] **Неделя 3**: Наведение порядка в стилях. Методология БЭМ. Знакомство с препроцессорами или *Tailwind CSS*.
- [ ] **Неделя 4**: Адаптивность. Медиа-запросы. 
  *   ** Практический воркшоп:** Создание первого командного репозитория и верстка карточки студента через Pull Request.

### Блок 2: Ядро TypeScript
***Октябрь – Ноябрь** | Переход к строгой типизации для исключения багов на этапе написания кода.*

- [ ] **Неделя 5**: Примитивные типы данных в TS (`string`, `number`, `boolean`, `arrays`, `any`/`unknown`).
- [ ] **Неделя 6**: Типизация функций. Стрелочные функции, аргументы и типы возвращаемых значений (`return types`).
- [ ] **Неделя 7**: Объекты. Сравнение `interface` и `type`. Моделирование сущностей CRM (`Student`, `Teacher`, `Lesson`).
- [ ] **Неделя 8**: Продвинутые типы: `Union types`, конструкции `Enum` и литеральные типы.
- [ ] **Неделя 9**: TypeScript в браузере. Работа с DOM, типизация событий клика и отправки форм.
- [ ] **Неделя 10**: Асинхронный TypeScript. Принцип работы `Promises` и синтаксис `async/await`. Fetch-запросы.
- [ ] **Неделя 11**: Обобщения (`Generics`) — создание переиспользуемых функций, классов и интерфейсов.
- [ ] **Неделя 12**: **🏁 Контрольная точка №1:** Создание локального (CLI/Браузер) приложения для учета посещаемости группы на чистом TS.

### Блок 3: Frontend на React + TypeScript
***Декабрь – Февраль** | Сборка реактивного и динамического UI для административной панели.*

- [ ] **Неделя 13**: Экосистема React. Сборщик Vite. Компонентный подход. Типизация входящих параметров (`props`).
- [ ] **Неделя 14**: Реактивность. Хук `useState`. Локальное состояние и типизация сложных объектов в стейте.
- [ ] **Неделя 15**: Жизненный цикл компонента. Хук `useEffect`. Интеграция с API, загрузка списков.
- [ ] **Неделя 16**: Рендеринг массивов через `.map()`. Условный рендеринг компонентов. Правило ключей `key`.
- [ ] **Неделя 17**: Работа со сложными формами. Контролируемые компоненты. Интеграция `React Hook Form` + TS.
- [ ] **Неделя 18**: Клиентский роутинг. Настройка `React Router Dom`. Создание приватных путей авторизации (Private Routes).
- [ ] **Неделя 19**: Глобальный стейт-менеджмент. Работа с `Context API` или внедрение легкого менеджера состояний `Zustand`.
- [ ] **Неделя 20**: Кастомные хуки (`Custom Hooks`) как способ декомпозиции и выноса бизнес-логики из UI.
- [ ] **Неделя 21**: Скорость разработки. UI-фреймворки (*Shadcn/ui* / *Ant Design*) для быстрой генерации таблиц и графиков.
- [ ] **Неделя 22**: Продуктивность интерфейса. Мемоизация с помощью `useMemo`, `useCallback` и `React.memo`.
- [ ] **Неделя 23**: Интеграция с REST API через Axios. Изоляция запросов в сервисный слой.
- [ ] **Неделя 24**: **🏁 Контрольная точка №2:** Защита фронтенд-интерфейса CRM (полноценный дашборд с расписанием и профилями).

### Блок 4: Углубленный MySQL
***Март** | Проектирование надежной архитектуры хранения данных образовательного центра.*

- [ ] **Неделя 25**: Реляционные базы данных. Установка MySQL сервера. Написание базового CRUD (`SELECT`, `INSERT`, `UPDATE`, `DELETE`).
- [ ] **Неделя 26**: Проектирование схемы данных (ER-диаграммы). Связи `1:M` (Группа -> Студенты) и `M:M` (Студент <-> Курсы). Внешние ключи.
- [ ] **Неделя 27**: Сложные SQL-операции. Фильтрация, группировки (`GROUP BY`, `HAVING`) и агрегатные функции для аналитики доходов.
- [ ] **Неделя 28**: Объединения таблиц. `INNER JOIN`, `LEFT/RIGHT JOIN`. Создание индексов для оптимизации тяжелых запросов.

### Блок 5: Backend на TypeScript
***Апрель** | Создание безопасной и быстрой серверной прослойки.*

- [ ] **Неделя 29**: Среда выполнения Node.js. Архитектура сервера. Настройка серверного TS. Инициализация `Express.js`.
- [ ] **Неделя 30**: Проектирование REST API точек. Обработка query-параметров (`req.query`), параметров пути (`req.params`) и тела (`req.body`).
- [ ] **Неделя 31**: Взаимодействие сервера с СУБД. Настройка современной ORM системы (*Prisma ORM* или *TypeORM*).
- [ ] **Неделя 32**: Middleware концепция. Логирование, глобальный перехват ошибок. Валидация схем запросов через библиотеку `Zod`.

### Блок 6: Безопасность и Сквозной проект
***Май** | Связка всех частей в единую экосистему и релиз модулей.*

- [ ] **Неделя 33**: Аутентификация. Хеширование пользовательских паролей (`bcrypt`). Внедрение сессий на базе `JWT токенов` (Access/Refresh).
- [ ] **Неделя 34**: Безопасность сети. Настройка CORS-политики. Деплой full-stack приложения: сервер (VPS/Render), фронт (Vercel). Конфигурация `.env`.
- [ ] **Неделя 35**: Командная сборка. Интеграция студенческих фронтенд-интерфейсов с собственными серверами и реальной БД.
- [ ] **Неделя 36**: ** Финальный Хакатон:** Презентация и защита готовых автономных модулей (например, «Модуль онлайн-оплаты» или «Интерактивный журнал оценок»). Отбор лучших студентов в основную команду разработки стартапа.
